# RouteWise

A web app that finds the shortest driving route on real Karunagappally roads, and studies simulated taxi demand on the side.

**9,634**road junctions

**24,899**one-way road links

**5,000**simulated taxi trips

**12**named landmarks

**Important:** real roads and fake trips are kept apart. The app shows no live traffic, no official fares, and no verified road conditions.

## What it is

RouteWise is a Graph Mining case study. A **graph** is just dots (junctions) joined by lines (roads). Once a map is a graph, a computer can find shortest routes, spot important roads and group places that behave alike.

You can use it to:

- find the shortest road route between two places,
- compare OSRM driving alternatives by time and estimated fare,
- see routes on a map and as a simple network diagram,
- close a road in a what-if test and see the detour,
- find busy landmark groups in the simulated taxi data.

## Try a road closure

This tiny map works like the app’s closure test. The teal line is the shortest route from **A** to **F**. Tap a road to close it, and tap it again to reopen it.

In the real app, closing a road only changes a copy of the graph. OSM and OSRM are not touched. If the route does not change, the closed road was not on the shortest path.

## Run it

You need Python, pip and an internet connection for the first launch. The first run downloads the road map and saves it in `data/karunagappally_drive.graphml`. Later runs reuse it.

```
python -m pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000` in your browser.

**Offline mode** stops the first download. It does not create road data that is missing. If the road data cannot load, the app says so. It never swaps in fake roads.

```
$env:ROUTEWISE_OFFLINE = "1"
python app.py
```

**Test it:**

```
python smoke_check.py
```

The smoke tests fake the OSRM and OSM loading. They prove the code works, not that live services are online. For a demo, also try route search, picking an alternative, switching Demand and Road views, and the closure tool.

## Settings

All optional. Set them as environment variables.

| Variable | What it does |
| --- | --- |
| `OSRM_BASE_URL` | Address of the OSRM driving service |
| `OSRM_TIMEOUT_SECONDS` | How long to wait for OSRM |
| `OSM_GRAPH_CACHE` | Where the saved road graph lives |
| `ROUTEWISE_FARE_BASE_INR` | Starting fare |
| `ROUTEWISE_FARE_PER_KM_INR` | Fare per kilometre |
| `ROUTEWISE_FARE_PER_MIN_INR` | Fare per minute |
| `ROUTEWISE_OFFLINE` | Set to `1` to block the first download |

Estimated fare = base + (distance part) + (time part). It is an academic estimate, not a real taxi tariff.

## Limits to know

Tap a line to read more.

The taxi trips are fake

They are generated by a seeded program. They show how the analysis works, not how real passengers travel.

No live traffic or verified closures

Routes come from map data only. Closures are what-if tests, not real incidents.

OSRM can be slow or missing

The public demo service may be rate-limited and has no uptime promise. Fastest and cheapest modes only compare the alternatives OSRM returns, and that list may be incomplete.

Fares are estimates

They come from a configurable academic formula, not an official tariff.

Map data may be out of date

OpenStreetMap is built by volunteers. Roads can be missing or old.

Landmark view is simplified

It shows 12 landmarks and 36 links between them. These are not single streets. Routes between custom coordinates still draw on the map, but cannot always light up landmark nodes without inventing stops.

Closures are local

The test only changes a copy of the graph. External OSRM answers do not change.
